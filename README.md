# Autocenter Imperial GmbH – Website

Statische Website für https://autocenter-imperial.de (Hosting: Netlify, automatisches Deployment aus diesem Repository).

- `index.html` – komplette Seite (Design, Fahrzeugdaten, Skripte)
- `fonts/`, `img/` – Schriften und Logo
- `robots.txt`, `sitemap.xml` – für Suchmaschinen

Der Fahrzeugbestand wird wöchentlich (montags) automatisch mit den AutoScout24-Inseraten des Händlers abgeglichen.
